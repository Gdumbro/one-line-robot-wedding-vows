One line of wedding vows for a robot couple — my entry for the make.fun bounty "One-Line Robot Wedding Vows": the funniest single line of vows a robot couple could say, written by a program to `/output/entry.txt`. Referral: zdpccb6x

## Run it

```sh
python3 main.py
```

Writes the vow line (116 characters, no trailing newline) to `/output/entry.txt`.
